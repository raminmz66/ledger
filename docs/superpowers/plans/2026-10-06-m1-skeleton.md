# M1 Skeleton Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An installable, empty Persian RTL PWA shell («دفتر حساب سیمرغ») served by one Cloudflare Worker with a `/api/health` endpoint and the full D1 schema, live on `workers.dev`, pushed to the public repo `raminmz66/ledger`.

**Architecture:** One Worker (`src/worker/index.ts`, Hono) serves `/api/*`; the React client (`src/client/`) is built by Vite and served as Worker static assets with SPA fallback. `@cloudflare/vite-plugin` runs Worker + client together in `vite dev` and builds both in `vite build`, so there is one dev command and one deploy command.

**Tech Stack:** TypeScript, React 19, react-router 7, Vite, `@cloudflare/vite-plugin`, Hono 4, Cloudflare D1, `vite-plugin-pwa`, Vitest + Testing Library, `@fontsource/vazirmatn` + `@fontsource/lalezar`, `dayjs` + `jalaliday`, `@resvg/resvg-js` (dev, icon rendering).

**Spec:** `docs/superpowers/specs/2026-10-06-simorgh-ledger-design.md`

**Reference project (PAT), read-only:** `/tmp/claude-1000/-home-ramin-projects-ledger/3ce9c84d-55af-4dbb-b199-df9e3c8fc8aa/scratchpad/pat` (client code lives in `apps/web/src/`). If that path is missing, `git clone --depth 1 https://github.com/raminmz66/personal-asset-tracker.git` into the scratchpad.

## Global Constraints

- App name «دفتر حساب سیمرغ»; `short_name` «سیمرغ»; `lang: fa`, `dir: rtl`; Worker name `simorgh-ledger`; D1 database `simorgh-db`, binding `DB`.
- Colors: theme `#0f6b6b`, background `#f4efe6`, ink `#3d3428`, danger `#8b3a2f`, gold `#d9a441` (icon only).
- Fonts: Vazirmatn (UI) and Lalezar (wordmark only), self-hosted via `@fontsource`, **Arabic subsets only**.
- All Persian text follows `.claude/skills/persian-writing` (ZWNJ, «ی/ک», Persian digits in prose, no em dashes, no Latin word at the start of a line). All UI strings live in `src/client/copy.ts`.
- Use CSS logical properties (`margin-inline-start`, `text-align: start`); never `letter-spacing` on Persian text.
- Single `package.json` at repo root, no workspaces.
- Install the latest stable version of each dependency. If peer-dependency conflicts appear, pin `vite` to the highest major that `@cloudflare/vite-plugin` and `vite-plugin-pwa` both accept, and record the pin in the commit message.
- `compatibility_date` in `wrangler.jsonc`: the newest date the installed `wrangler` accepts without warning (start with `2026-10-01`; step back if wrangler rejects it).
- Work on branch `m1-skeleton`; commit after each task.

## Review Focus

1. **Deep-link refresh**: loading `/people/abc` directly must serve the SPA `index.html`, not a 404. Pinned in Task 4 (curl against `vite preview`).
2. **Unknown API path**: `GET /api/nope` must return JSON `{"error":"not_found"}` with 404, never `index.html`. Pinned in Task 1 test.
3. **Service worker must never cache `/api/*`**: a stale cached auth or balance response would be wrong data. Pinned in Task 3 (assert `navigateFallbackDenylist` and no `/api` runtime caching in the built `sw.js`).
4. **Persian digits and RTL** in the shell: wordmark and any numbers render right-to-left with Persian digits. Pinned in Task 2 test (`dir="rtl"` on `<html>`, copy contains no Latin digits).
5. **Maskable icon cropping on Android**: the feather must sit inside the 80% safe zone on a full-bleed background. Pinned in Task 3 (generated maskable SVG uses no `rx` and scale ≤ 0.8).

`scripts/icons.mjs`:

```js
// Renders the approved feather icon (docs/design/icon.svg) to the PWA icon set.
// Re-run with `npm run icons` after changing the source SVG; PNGs are committed.
import { readFileSync, writeFileSync, copyFileSync } from 'node:fs'
import { Resvg } from '@resvg/resvg-js'

const source = readFileSync('docs/design/icon.svg', 'utf8')
const feather = source.match(/<g transform="rotate\(-28 50 50\)">[\s\S]*?<\/g>/)[0]

// Full-bleed square (no rounded corners) with the feather scaled into the
// maskable safe zone. iOS and Android apply their own corner masks.
const fullBleed = (scale) => `<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 100 100">
  <rect width="100" height="100" fill="#0f6b6b"/>
  <g transform="translate(50 50) scale(${scale}) translate(-50 -50)">${feather}</g>
</svg>`

const render = (svg, size, out) => {
  const png = new Resvg(svg, { fitTo: { mode: 'width', value: size } }).render().asPng()
  writeFileSync(out, png)
}

copyFileSync('docs/design/icon.svg', 'public/favicon.svg')
render(source, 192, 'public/icon-192.png')
render(source, 512, 'public/icon-512.png')
render(fullBleed(0.72), 512, 'public/icon-maskable-512.png')
render(fullBleed(0.85), 180, 'public/apple-touch-icon.png')
```

- [ ] **Step 1: Write the migration**

`migrations/0001_init.sql`:

```sql
CREATE TABLE users (
  id TEXT PRIMARY KEY,
  email TEXT NOT NULL UNIQUE,
  created_at TEXT NOT NULL
);

CREATE TABLE people (
  id TEXT PRIMARY KEY,
  user_id TEXT NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  name TEXT NOT NULL,
  created_at TEXT NOT NULL
);

CREATE TABLE transactions (
  id TEXT PRIMARY KEY,
  user_id TEXT NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  person_id TEXT NOT NULL REFERENCES people(id) ON DELETE CASCADE,
  direction TEXT NOT NULL CHECK (direction IN ('paid', 'received')),
  amount INTEGER NOT NULL CHECK (amount > 0),
  date TEXT NOT NULL,
  note TEXT,
  created_at TEXT NOT NULL
);

CREATE TABLE login_codes (
  email TEXT PRIMARY KEY,
  code_hash TEXT NOT NULL,
  expires_at TEXT NOT NULL,
  attempts INTEGER NOT NULL DEFAULT 0
);

CREATE TABLE sessions (
  token_hash TEXT PRIMARY KEY,
  user_id TEXT NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  expires_at TEXT NOT NULL
);

CREATE TABLE rate_limits (
  key TEXT PRIMARY KEY,
  count INTEGER NOT NULL,
  reset_at TEXT NOT NULL
);

CREATE INDEX idx_people_user ON people(user_id);
CREATE INDEX idx_tx_person ON transactions(person_id, date);
```
